03 / ZERO MIGRATION

同一个引擎，
零迁移。

它不替换你的引擎。首次启动检测本机官方 DSH，连上后读的还是同一个 ~/.dsh。

不迁移、不复制。读的还是 ~/.dsh，官方客户端随时可以继续用。

04 / NATIVE

没有壳。
只有 macOS。

Flutter 界面、Swift 平台层、原生 Node 引擎。没有 Electron，没有内嵌浏览器。

# 或下载 DMG（Apple Silicon / macOS 12+）

# 未签名构建被 Gatekeeper 拦住时
$ xattr -dr com.apple.quarantine "/Applications/DSH Go Mac.app"
首次启动 · 选「连接官方 DSH」或「本机」下载 DMG ↗
  1. 01已在用官方 DSH：启动后选「连接官方 DSH」，不装运行时，读同一个 ~/.dsh。
  2. 02想让 Mac 自己跑：选「本机」，安装约 750 MB 运行时。
  3. 03连远程：选「远程主机」，SSH 或 DSH Remote。
