# 同一个 DSH，我为什么换了个客户端

官方 DeepSeek Harness 的 Mac 客户端没什么问题。引擎、模型、插件都在，能干活。

但我每天真正盯着看的，是**对话这一层**：一轮任务跑到哪了、刚才那步在干什么、改了哪些文件、花了多久、下一步要不要我批。这些信息在官方界面里不是没有，只是不够顺手。于是我把 DSH Go 的客户端搬到了 Mac——**不是换引擎，是换一个我更愿意天天看的界面**。

它连的还是你现在的 DSH：选「本地官方 DSH」，对话、模型、插件原样都在，不用迁移、不用重新登录、不用装第二套运行时。

---

## 一、过程信息：不是只有最后一段答案

官方客户端的主视图是「消息」。DSH Go Mac 把一轮任务的**过程**也摆出来了：

- 思考了几秒、运行了什么命令、耗时多少，每一条都是独立的一行
- 右侧「运行详情」有五个页签：**轨迹 / 改动 / 文件 / 进度 / 上下文**
- 顶部直接给三个数：**用时、步骤、改动文件**
- 「改动」里点进去就是 diff，不用去翻日志

截图里那一轮：`54:58`、`73 步`、`2 个文件`——这三个数让我不用点开任何东西，就知道它是不是在认真干活。

这不是「信息更多」的问题，是**信息密度和层级**的问题。过程默认折叠成一行，想深挖再点开；需要你决策的（审批、提问）单独浮出来，不藏在消息流里。

---

## 二、动效：不是为了好看，是为了「不打断」

移动端做动效是被迫的（屏幕小、要用手势）；桌面端做动效是选择。我保留 DSH Go 那套动效，是因为它解决了一个具体问题：**长任务等待时的焦虑**。

- 思考中的胶囊会呼吸，不是死转圈
- 工具行逐条滑入，带耗时；折叠/展开有连续的高度动画
- 侧栏、抽屉、页面转场都是同一套缓动，不会「啪」地跳出来
- 桌宠在桌面上跑，任务完成会冒气泡——听起来花哨，但它是一个不占屏幕的进度提示

这些加起来的效果是：你不需要一直盯着窗口，余光扫一眼就知道「还在跑 / 卡住了 / 等你批」。

---

## 三、UX：把高频动作压到一次点击

几个我每天都在用的：

- **通知上直接允许 / 拒绝**，点通知回到对应对话——不用先切回 App 再找那个待批的会话
- **会话抽屉**：置顶、归档、未读、待确认，一个列表全管
- **输入框上方的快捷胶囊**：常用动作不用翻菜单
- **分享卡**：一轮对话直接导出成图，带两个二维码
- **手机接管**：手机版 DSH Go 加一个 SSH 主机，就能连回 Mac 上的引擎，出门在外也能接着批

---

## 四、和官方是什么关系

不是替代，是**同一引擎的另一个客户端**：

| | 官方客户端 | DSH Go Mac |
| --- | --- | --- |
| 引擎 | 官方 DSH | 官方 DSH（直连）或自带引擎 |
| 数据 | `~/.dsh` | 连官方时就是同一份，不迁移 |
| 界面 | 官方 Web/Electron 风格 | DSH Go 的原生 Flutter 界面 |
| 过程信息 | 消息为主 | 轨迹/改动/文件/进度/上下文 |
| 通知审批 | 基础 | 通知上直接允许/拒绝 |
| 平台 | macOS | macOS（Apple Silicon） |

官方客户端适合「什么都用官方」的人；这个客户端适合**每天要跑很多轮任务、需要看清过程、又不想被界面拖慢**的人。

---

## 五、它不适合谁

- 只用官方、不想装第三方客户端的人
- 需要 Intel Mac 的人（目前只做 arm64）
- 需要签名/公证分发的人（现在是未签名构建，首次要右键打开）
- 需要 Mac 操控的人（原「手机操控」还没移植，入口保留但显示未就绪）

---

## 六、怎么开始

1. 下载 DMG，拖进 `Applications`，右键 →「打开」
2. 启动后选 **「本地官方 DSH」**（如果你已经在用官方），直接连上
3. 想用自带引擎就选「本地 DSH · 自带」，一键安装运行时
4. 手机连接：`设置 › 本机引擎 › 手机连接`，按页面上的 IP / 用户名 / 密码说明，在手机版 DSH Go 里加一个 SSH 主机
