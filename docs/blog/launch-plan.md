# DSH Go Mac 推广作战计划（修正版）

> **定位纠正**：这不是「Mac 版 DSH / 不装 Linux」——官方 Mac 客户端早就有。
> 这是**同一个 DSH 引擎的另一个客户端**，卖点是 **UI / UX / 过程信息 / 动效**。
>
> 一句话：**同一个引擎，一个更现代、更顺手的客户端。**

---

## 一、三个实证卖点（所有内容围绕这三个）

1. **过程信息详细**
   - 一轮任务：用时 / 步骤 / 改动文件三个数直接给
   - 运行详情五页签：轨迹、改动、文件、进度、上下文
   - 思考、工具、耗时逐行展开，点「改动」直接看 diff
2. **UI/UX 流畅**
   - 会话抽屉、置顶/归档/未读/待确认
   - 通知上直接允许/拒绝，点通知回到对话
   - 输入框快捷胶囊、分享卡、手机接管
3. **动画现代**
   - 思考胶囊呼吸、工具行滑入、折叠展开连续高度、页面统一缓动
   - 桌宠作为不占屏的进度提示

**不要**再讲：移植架构、PRoot、Kotlin→Swift、不装 Linux。这些是可信度，不是钩子。

---

## 二、目标人群

- **已经在用官方 DSH 的 Mac 用户**（核心）：不用迁移，装个客户端连上去
- 觉得官方界面「信息不够/不够顺」的人
- 对动效和交互敏感的设计师/开发者
- DSH Go 手机版用户（可连回 Mac）

## 四、15 秒演示脚本（最重要）

| 时间 | 画面 | 字幕 |
| --- | --- | --- |
| 0–3s | 启动 → 会话抽屉滑出，列表紧凑 | 同一个 DSH，不用迁移 |
| 3–6s | 发一句任务，思考胶囊呼吸、工具行逐条滑入 | 过程信息全在 |
| 6–9s | 点开运行详情，切「轨迹/改动/文件」 | 用时、步骤、改了什么 |
| 9–12s | 通知弹出，直接点「允许」 | 不用切回 App |

录屏注意：60fps、不要加速、不要配乐压过原声；动效本身是卖点。

## 五、可直接复制的文案

### 5.1 V2EX

**标题**：同一个 DSH，我为什么换了个客户端

> 官方 Mac 客户端没问题，引擎、模型、插件都在。但我每天盯的是对话这一层：这轮跑到哪、刚才在干嘛、改了哪些文件、要不要我批。
>
> 所以把 DSH Go 的客户端搬到了 Mac——不换引擎，连你现在的官方 DSH，对话和插件原样都在。
>
> 三个我离不开的点：
> - 过程信息：用时/步骤/改动文件，轨迹/改动/文件/进度/上下文五个页签，点改动看 diff
> - 通知上直接允许/拒绝，点通知回到对话
> - 动效是移动端那套：呼吸胶囊、工具行滑入、连续折叠，不是 Electron 的硬切
>
> 未签名，首次右键打开；只做 Apple Silicon / macOS 12+。
> 仓库：https://github.com/BillWGong/dsh-go-mac
> 视频：https://www.bilibili.com/video/BV1njxJ6WE59/

### 5.2 小红书

**标题**：同一个 DSH，我换了个更顺手的客户端

> 官方 DSH 的引擎没问题，我换的是界面。
> 这轮任务用时、步骤、改了哪些文件，直接摆在旁边；点开就是轨迹和 diff。
> 动效很顺，通知上就能点允许，手机还能连回来接着批。
> 开源免费，Mac 直接下👇
> #DSH #AI工具 #macOS #效率工具 #独立开发
